Hours worked: ~5-6h

Long, gallery-heavy session — three new content types went up (Fine Arts, Animation Shorts, a full narrative short's project page), plus a real bug fix and a fair bit of iteration on how a lightbox should behave when the media changes shape from image to video.

Fine Arts gallery (renamed from Paintings)

  • Rebuilt as a proper bento grid — capped at 4 columns, row-spans computed in JS from each image's real aspect ratio instead of force-cropping everything to one shape
  • 37 real pieces loaded in, each with a researched title and medium (pencil, charcoal, oil, digital) judged from the actual artwork
  • Whole feature renamed Paintings → Fine Arts site-wide — files, folder, CSS classes, manifest, nav labels
  • Established the ongoing workflow going forward: rename a file in the private working folder, and it gets synced into the site's served copy plus the manifest on request
Bento grid — row-span packed by real aspect ratio

Lightbox, and a real bug

  • Click any tile to view it fullscreen with title/medium — image stays dead-centered, details panel fixed to the right, click outside the image closes it
  • Found the actual cause behind two rounds of "it's broken" reports: .lightbox { display: flex } had no .lightbox[hidden] { display: none; } override, so the browser's built-in [hidden] rule was silently losing to the author stylesheet — the lightbox was always visible regardless of the hidden attribute, which explained both "shows by default" and "click outside doesn't close it" from the same root cause

Baby John — new project page

  • Single VFX shot built solo in Blender — a school bus sinking underwater — filled in from concept sketch through to the final animated clip
  • Includes a Cycles-vs-Eevee lookdev comparison explaining the actual tradeoff made: Cycles for physical accuracy, Eevee for iteration speed on a moving-camera shot, which is why the final sink was rendered in Eevee

Animation Shorts — new gallery, video this time

  • Same bento-grid system as Fine Arts, but every tile is a real video clip, not an image
  • Tiles autoplay muted and looped by default (no click or hover needed), gated behind an IntersectionObserver so only on-screen clips are actually decoding — with up to 21 clips on one page, autoplaying all of them regardless of scroll position would have been a real performance problem
  • 21 personal/hobby clips compressed from ~509MB down to ~78MB total
  • Lightbox variant added for video: same centered-media pattern as Fine Arts, but details stack below the video instead of floating to the right — a fixed side panel would've overlapped a 16:9 clip at lightbox width, so stacking was the fix

Selected Work cleanup

  • Removed the category label from under every card in the homepage carousel — thumbnail and title only now, keeping the filter tabs above doing the categorizing instead of repeating it on every card
  • Renamed the "3D Visualization" filter tab to "3D Vis / CGI"

Madan and Family — first full narrative short on the site

  • A college graduation short co-written, designed, and animated with classmate Nilesh — didn't fit any existing category, so it got its own new "Short Films" filter instead of being force-fit into Production Design or 3D
  • Project page built as a real case study: hero video (click-to-play with poster, not autoplay — a 2:36 cut with music isn't a background loop), synopsis, character design breakdown for the three leads, and a "key scenes" row of three looping clips converted from the original GIFs (14-17MB each down to ~0.5-0.6MB)
  • Full 129-shot storyboard pulled out into its own gallery page — plain sequential grid, not the dense-packed bento style, since shot order actually matters here and grid-auto-flow: dense would have scrambled the sequence
  • The storyboard link on the project page went through a couple of rounds: text button → small thumbnail card → a proper "stack of cards" visual (two rotated card edges peeking out behind the thumbnail, fanning further out on hover)
  • Storyboard gallery cross-linked both ways: a card for it now lives under the "Storyboarding & Concept Art" filter on the homepage, and the gallery itself links back to the main project page at the bottom
