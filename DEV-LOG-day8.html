Hours worked: ~8-9h

Almost the entire day went into one thing: a second homepage. Sanjay liked the restraint of a reference site (cyze.dev) and asked for a v2 built in that direction, kept alongside v1 rather than replacing it — so this log is mostly the story of that build, plus one real content-integrity call on the v1 side.

v2 — a second homepage, built to compare

  • Tagged the pre-v2 state (v1-snapshot) before touching anything, then built the new homepage entirely under /v2/ — root index.html untouched apart from one footer link across to it
  • First pass was "inspired by" the reference site's restraint. Sanjay asked for closer fidelity, so the actual compiled CSS/HTML of cyze.dev got pulled and inspected directly — its real OKLCH color-token system, named motion durations/easings, LQIP blur-up image loading, and squircle-cornered cards all got reverse-engineered and rebuilt properly rather than approximated
  • Structure settled at Hero → Feed → Footer, matching the reference exactly — no separate About section, no contact form on first pass (that changed later today, see below)

Design system pass — bento grid, black & white, real hierarchy

  • The work feed went through two layout systems in one day: a flex-based masonry column-balancer first, then swapped for a proper bento grid once Sanjay asked for it — reused the exact row-span-by-real-aspect-ratio technique already proven on the Fine Arts gallery, just capped at 2 columns instead of 4
  • Palette reworked from a warm-neutral OKLCH scheme to true black-and-white, with the sitewide tiger-orange accent refined per theme (deepened for light mode, lightened for dark) so it stays sparing rather than becoming a wash
  • Hero type now runs a strict ×1.6 modular scale across three tiers — identity (name) → context (role) → supporting text — instead of three sizes picked by eye
  • Typography got its own live decision tool: a temporary 3-way toggle right in the hero (Bricolage Grotesque / Montserrat Black / a free stand-in for a paid font Sanjay didn't own yet) so he could compare in context instead of from a description. Montserrat Black won; the toggle came back out once it was picked

MANTHIRA — went undisclosed, sitewide

  • Sanjay flagged that the MANTHIRA case study's storyboard/previz imagery hadn't cleared disclosure with the film's team yet — the page needed to become text-only, process and experience only
  • Tracing where that same title-card image and intro video actually appeared turned up four more spots: twice in v1's homepage carousel, once in v2's feed, and once as the entire premise of a separate "MANTHIRA — Title Animation" page. All four came down for consistency — the Title Animation page unlinked (not deleted) until disclosure clears, the carousel/feed cards reduced to a plain "Undisclosed — under NDA" tile
  • The case-study page itself kept every word of its process writing intact, just folded the captions the removed images used to carry into the existing prose instead of losing that content

Hero: portrait, header, interactions

  • Sanjay's actual portrait went in — cropped properly by finding the real alpha-threshold content bounds first (a naive transparency crop was fooled by faint stray pixels stretching to the canvas edges), then a tighter chest-level recrop with a light bottom dissolve so it doesn't cut off hard
  • Two versions of the portrait (white outfit / black outfit) now swap automatically with the theme — whichever reads better against that background
  • The floating pill header is v1's own "collapsed" header pattern, reused wholesale — wordmark, theme toggle, and a Contact Now button in one rounded capsule
  • The SANJAY→SANACE hover animation on the name got rebuilt to actually match v1's real flip mechanism (a 3-glyph vertical track per letter) instead of a simplified version — and the letter-spacing bug that came with it got fixed by measuring each glyph's real rendered width in JS rather than forcing every letter into a shared box
  • One interaction pattern — an icon that reveals from zero width on hover — got generalized into a shared class and applied everywhere: hero links, the header CTA, footer socials. Same for v1's magnetic hover (buttons pull slightly toward the cursor), now on every clickable element in v2
  • Found and fixed a real bug: the theme toggle's sun/moon icons were both rendering at once because a more specific CSS rule was silently beating the one meant to hide the inactive icon
  • Theme switching now ripples out from the click point via the View Transitions API — took two rebuilds to get right, since animating the transition pseudo-element directly has spotty cross-browser support; landed on injecting the keyframe fresh per click with the coordinates baked in as literal values
